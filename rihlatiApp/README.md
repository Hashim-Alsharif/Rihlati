# تطبيق رِحلتي من فريق سراج

واجهة عربية ومتعددة اللغات للأعضاء ومكاتب الدعوة على الهاتف والتابلت، بشعار رحلتي الأصلي وألوان كحلية وسماوية وحقوق فريق سراج. التقنية: JavaScript وCSS وCapacitor 8 مع مشروعي Android وiOS. لا توجد قاعدة بيانات أخرى أو مفتاح OpenAI داخل التطبيق.

## التشغيل في المتصفح

Node.js 22+ ثم من هذا المجلد:

```sh
npm ci
npm run build
npm test
```

شغّل خادم `../Rihlati` وافتح `http://localhost:8080/app/`. زر العودة يفتح الموقع، والموقع يحتوي زر «تجربة التطبيق». الحسابات والتذاكر والرحلة والمكتبة مشتركة؛ جلسة التطبيق مستقلة عن جلسة الويب.

## الملفات

- `src/`: التصميم ومكونات الهاتف وتكامل الوظائف الأصلية.
- `scripts/build.mjs`: نسخ قائمة محددة من منطق الويب وتجميع واجهة الهاتف.
- `scripts/configure-native.mjs`: الأيقونات وشاشات البداية من الشعار نفسه.
- `android/`, `ios/`: مشروعا المنصتين.
- `www/`: ناتج مولّد؛ لا تعدله يدويًا ولا ترفعه للمستودع.
- `tests/`: اختبارات محلية بلا خدمات مدفوعة.

قارئ PDF محلي باستخدام PDF.js مع تعطيل تنفيذ سكربتات PDF. الخطوط محلية. لا تُخزّن المحادثة في مخزن offline دائم. العودة من الخلفية توقف التسجيل والتشغيل الصوتي لحماية الخصوصية. ميزات الجهاز تحتاج تحققًا فعليًا على Android وiOS.

## بناء نسخة متصلة بالدومين

على PowerShell بعد اعتماد عنوان HTTPS:

```powershell
$env:RIHLATI_API_ORIGIN='https://YOUR-DOMAIN'
Remove-Item Env:RIHLATI_LOCAL_DEBUG -ErrorAction SilentlyContinue
npm run sync
npm run android
```

على macOS:

```sh
RIHLATI_API_ORIGIN=https://YOUR-DOMAIN npm run sync
npm run ios
```

Capacitor 8 يحتاج Android SDK 36 وبيئة Java متوافقة، وiOS يحتاج Mac وXcode 26 أو أحدث متوافق والتوقيع بحساب المطور. راجع [متطلبات Capacitor الرسمية](https://capacitorjs.com/docs/getting-started/environment-setup). لم يُبنَ IPA على Windows. معرّف الحزمة الحالي `com.siraj.rihlati` يحتاج اعتماد الفريق قبل المتاجر. لا تحفظ مفاتيح التوقيع أو كلماتها في Git.

## نسخة Android المحلية

تم بناء APK Debug في `android/app/build/outputs/apk/debug/app-debug.apk`. هذه النسخة مضبوطة على `http://127.0.0.1:8080` للتطوير فقط، ولن تصل إلى جهاز المطور تلقائيًا من هاتف آخر. يمكن للمطور استخدام جهاز USB مأذون و`adb reverse tcp:8080 tcp:8080` مع تشغيل الخادم. ليست نسخة التحكيم أو المتجر. بعد توفير HTTPS أعد البناء واختبر على أجهزة فعلية ثم وقّع نسخة التوزيع. لا ترفع APK المحلي على أنه نسخة عامة عاملة.

## الصلاحيات والأمان

`runtime.js` يوجّه طلبات التطبيق إلى `/app-api/`. الخادم يرفض دخول الأدمن برسالة استخدام الويب، ويمنع مسارات الإدارة حتى مع تعديل الواجهة أو استخدام جلسة ويب. العضو يرى بياناته والمكتب يرى نطاقه فقط. الطلبات الخارجية لا تتلقى بيانات اعتماد تلقائية. إعداد الإصدار لا يسمح بمرور HTTP غير المشفر؛ استثناء loopback في Android خاص بالتطوير. لا يوجد `server.url` يحمل واجهة خارجية داخل WebView.

## التحقق وحدود الإصدار

81 اختبار Python للمشروع الكامل، و7 اختبارات خاصة بالتطبيق، وبناء Android Debug. فُحص تجاوب التخطيط بعروض 320 و390 و768 و1024 و1366، وقراءة PDF ودخول المستفيد وتصعيد السؤال ومنع الأدمن وعرض مساحة المكتب محليًا. هذه ليست شهادة دعم لجميع الأجهزة أو تدقيق وصول شامل. جلسات HTTP الأصلية والميكروفون والصوت والرفع وفتح الكتب على أجهزة Android وiOS، والتوقيع ومتطلبات المتاجر، ما زالت بحاجة لاختبار. لا توجد مكالمات AI مدفوعة في هذه الاختبارات.
