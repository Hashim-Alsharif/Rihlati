# رِحلتي — فريق سراج

منصة ترافق المسلم الجديد: رحلة تعليمية، أسئلة شائعة، مساعد يستند إلى مكتبة موثقة، سؤال كتابة وصوت، استماع للجواب، وتذاكر يتابعها المختصون. بناء وتطوير المشروع: **فريق سراج**.

هذا المجلد `Rihlati` هو جذر الويب والخادم. التطبيق في المجلد الشقيق `rihlatiApp`. افتح المجلد الأب الذي يحتويهما معًا في VS Code للعمل على المشروع الكامل. جميع المسارات التالية نسبية إلى `Rihlati`، ولا تتطلب اسم مستخدم أو مسار جهاز بعينه. أصل الفكرة محفوظ في [docs/idea.docx](docs/idea.docx)، والبنية المستمرة في [PROJECT_ARCHITECTURE.md](PROJECT_ARCHITECTURE.md).

## التشغيل على جهازك الآن

شغّل `Start-Rihlati.cmd` ثم افتح [رِحلتي](http://localhost:8080/). بعد إعادة تشغيل الجهاز شغّل الملف مجددًا. إغلاق المتصفح لا يوقف الخادم. الملف يتحقق من المنفذ ولا يوقف خدمة أخرى.

حساب الإدارة الرئيسي: **`admin`**. كلمة البداية هي الكلمة التي حددها صاحب المشروع؛ لم نكتبها في الكود أو README. قبل استعمال الإدارة، أدخل بريدك وجوالك في «حسابي»، ثم غيّر كلمة البداية. الحساب الرئيسي محمي من الحذف والإيقاف وخفض الصلاحيات.

`localhost` هو جهازك فقط. لا تفتح `app/index.html` مباشرة ولا تستخدم Live Server؛ الواجهة تحتاج خادم Python وقاعدة البيانات.

### المسار والمراجعة واسم الحساب

- «مساري التعليمي» في الويب وتجربة التطبيق يعرض جميع الكتب المعتمدة، بما فيها المراجع العامة، مع فلتر مستقل للغة الكتب وخيار «كل اللغات». تبقى لغة الواجهة كما هي، وتُجمع مراجع `fil` و`tl` تحت Filipino دون تغيير بيانات المصادر.
- يمكن حفظ قراءة المراجع العامة أيضًا؛ تُسجّل القراءة دون تغيير نسبة تقدم المستويات أو مرحلة المستفيد. تظل القراءة وتقدمها مشتركة بين الويب والتطبيق.
- رأس الويب يعرض اسم الحساب ونوعه، واسم المكتب لموظفيه. الضغط على البطاقة يفتح «حسابي»، وتختفي البيانات عند الخروج.
- المرجع ذو «0 مقاطع» لا يُعتمد للإجابات دون نص صالح. زر «مراجعة النص» يفتح أول صفحة تحتاج المراجعة: افتح الأصل، أدخل النص الصحيح بلغته، أكد المقارنة، ثم احفظه. بعد ذلك يستطيع أدمن بصلاحية المكتبة اعتماد المرجع كخطوة مستقلة. هوية المراجع تؤخذ من الجلسة في الخادم ولا يمكن تزويرها بحقل النموذج.
- البطاقة الأمهرية غير المقروءة من دفعة المناهج لم تُعتمد آليًا؛ تحتاج مراجعًا يجيد الأمهرية لمطابقة النص بالأصل. تبقى حماية جودة المعرفة قائمة.

التحقق الأخير استخدم قواعد مؤقتة وبيانات اصطناعية: 95 اختبار Python، وثلاث مجموعات اختبارات JavaScript للويب (منها `scripts/test_journey_review.cjs`)، و7 اختبارات للتطبيق. جرى اختبار عرض الويب بعرض 320 بكسل بالعربية والإنجليزية وتجربة التطبيق بعرض 390 بكسل. لم تُجرَ اتصالات AI أو صوت حية، ولا بناء متجر Android/iOS في هذه الدفعة.

## الإعداد على جهاز جديد

المتطلبات: Python 3.12 أو أحدث متوافق مع الحزم المثبتة في `بخصوص requirements.txt`. على Windows من داخل هذا المجلد:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/setup_admin.py
.\Start-Rihlati.cmd
```

على Linux/macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/setup_admin.py
.venv/bin/python scripts/api_server.py
```

`setup_admin.py` يطلب كلمة بداية من طرفية مخفية الإدخال، ولا يستبدل أدمن موجودًا. لإنشاء نسخة من المشروع الحالي على خادم جديد، انقل البيانات الخاصة بأمان؛ Git وحده لا ينقل قاعدة المستخدمين أو الكتب أو المفتاح.

## البيئة واللغات البرمجية

| الجزء | التقنية |
| --- | --- |
| الواجهة | HTML، CSS، JavaScript، دون إطار بناء إلزامي |
| الخادم وواجهات API | Python + Flask، تشغيل Waitress |
| التخزين | SQLite مع ترحيلات إضافية، لا إعادة إنشاء للبيانات |
| كلمات المرور | Argon2id بملح عشوائي مستقل لكل كلمة |
| قراءة PDF | pypdf |
| معالجة الصور الشخصية | Pillow، إعادة ترميز PNG وحذف بيانات الصورة الأصلية |
| OCR العربي الاختياري | Node.js + Tesseract.js + Poppler |
| الذكاء والصوت | OpenAI عبر الخادم فقط، واسترجاع محلي عند غياب الخدمة |

الملفات الرئيسية:

- `app/`: الواجهة والترجمات والشعار؛ المسموح عرضه للمتصفح فقط.
- `scripts/api_server.py`: المسارات، التحقق من الجلسات والصلاحيات والعزل.
- `scripts/accounts.py`: المستخدمون والمكاتب والارتباطات وتجزئة كلمات المرور.
- `scripts/assistant_engine.py`: الحوار والتصعيد والتعلّم المراجع.
- `scripts/knowledge.py`: قاعدة المعرفة والفهرسة والصفحات والاستشهادات.
- `scripts/ai_provider.py`: الاتصال بخدمة الذكاء والصوت دون كشف المفتاح.
- `scripts/config.py`: ملف إعدادات الخادم الخاص.
- `data/rihlati.sqlite3`: قاعدة البيانات الحية؛ مستثناة من Git.
- `data/library/`: الكتب الأصلية، و`references/`: ملفات الرفع؛ مستثناة من Git.
- `data/avatars/`, `data/ocr/`, `data/backups/`, `data/logs/`: بيانات التشغيل الخاصة.
- `docs/`: التشغيل والأمان ومتطلبات المشروع. الأرشيف ليس مخططًا معتمدًا للنسخة الحالية.

## العضويات والصلاحيات

**المستفيد:** الاسم وكلمة المرور إلزاميان؛ الجوال والبريد اختياريان ما لم يفعّلهما الأدمن. يمكن إدخال اسم دخول مستقل لتجنب تشابه الأسماء؛ إن تُرك فارغًا يُستخدم الاسم. يختار المستفيد 1–3 مكاتب معتمدة. إن لم يوجد مكتب معتمد تستقبل الإدارة طلباته. يحفظ حسابه المحادثة والتقدم والتذاكر عبر الأجهزة.

**مكتب الدعوة:** يسجل المكتب واسم الموظف واسم الدخول وكلمة المرور. لا يحصل على بوابة العمل قبل اعتماد الإدارة. يستطيع مدير المكتب إضافة موظفين للمكتب نفسه. يرى المكتب تقدم المستفيدين المرتبطين به، والتذاكر الموجهة إليه فقط. لا تُعرض له المحادثات الخاصة الكاملة ولا بيانات مكاتب أخرى.

**الإدارة:** اعتماد المكاتب وإيقافها وأرشفتها؛ تعديل المستخدمين وبياناتهم وإيقافهم؛ تغيير ارتباط المستفيد؛ إسناد التذكرة إلى مكتب مرتبط ومعتمد؛ إضافة أدمن بصلاحيات محددة أو كاملة؛ إدارة المراجع واعتمادها؛ اعتماد التصحيحات وسحبها؛ متطلبات التسجيل؛ إعداد مفتاح الخدمة. لا يستطيع أدمن محدود الاستيلاء على حساب أدمن أعلى صلاحية. الحذف منطقي قابل للاستعادة من الحالة، ولا يمحو السجل التاريخي.

كل حساب يملك صفحة بيانات وصورة شخصية وتغيير كلمة مرور. كلمة المرور الجديدة من 8 إلى 128 خانة، تشمل حرفًا لاتينيًا كبيرًا (A–Z) ورقمًا (0–9) ورمزًا خاصًا مثل ! أو @ أو #. تبقى كلمات مرور الحسابات الحالية صالحة للدخول دون تغيير تلقائي. كلمات المرور ليست نصًا صريحًا أو تشفيرًا قابلًا للفك؛ هي تجزئة Argon2id بملح عشوائي في القاعدة. تغيير كلمة المرور ينهي الجلسات الأخرى. بعد تحقق بشري من الهوية يستطيع الأدمن إصدار كلمة مؤقتة لمدة 24 ساعة، تُعرض مرة واحدة ويجب تغييرها عند الدخول. البريد/SMS الآلي يحتاج مزوّد إرسال وإعدادات منفصلة؛ لا يدّعي الموقع أنه أرسل رسالة وهو لم يفعل.

## المكتبة والمساعد

احتُفظ بالمراجع الـ13 و640 صفحة و1080 مقطعًا الموجودة قبل تطوير العضويات، وبالمحادثات والتذاكر القديمة. الحسابات القديمة التجريبية لا تُنسب تلقائيًا إلى عضو جديد. الكتابان الأصليان ومناهج المستويات الثلاث باقية؛ المستوى الثالث يتضمن السيرة وفق الملفات المتاحة.

رفع PDF حتى 80 MB: اختر اللغة والمستوى والموضوع؛ يُسجل اسم المكتب أو الأدمن الرافع. يبدأ استخراج النص، ثم يراجع المكتب مصدره غير المعتمد، وتعتمده الإدارة قبل دخوله في الإجابات. الصفحات ضعيفة OCR تحتاج مراجعة. إعادة الفهرسة تحتفظ بالنصوص المراجعة وبالنص الأصلي المستخرج من Word والمرتبط بصفحات PDF. الحذف/سحب الاعتماد يستبعد المصدر من الاسترجاع ولا يحذف أصله وسجله. حد الرفع 10 محاولات/ساعة للحساب؛ الرسالة تبيّن مدة الانتظار مع `Retry-After` ولا تعني فقدان الكتب التي رُفعت.

دفعة «مناهج المسلمين الجدد» أُضيفت في 5 أكتوبر 2026: 46 مرجعًا جديدًا و10 موجودة حُفظت دون تكرار. حُوّلت 25 وثيقة Word و9 صور إلى PDF مع حفظ الأصول. التفاصيل والحدود في [تقرير استيراد المناهج](docs/LIBRARY_IMPORT_2026-10-05.md). الفهارس وجداول توزيع المنهج المميّزة بـ`navigation` لا تدخل في أدلة الإجابات؛ نصها واستشهاداتها باقية للفحص.

المساعد يسترجع مقاطع معتمدة مع الكتاب والصفحة. عند تفعيل الخدمة يعيد صياغة السؤال ويولّد إجابة من الأدلة ويتحقق منها آليًا مرة أخرى؛ هذا ليس اعتمادًا بشريًا أو ضمانًا لصحة كل جواب. عدم كفاية الدليل أو طلب المختص يفتح تذكرة بسياق السؤال. المستفيد يختار وجهة المختص من مكاتبه أو الإدارة. رد المختص يصل للمحادثة؛ لا يتحول تلقائيًا إلى معرفة موثوقة. تُرشح الإجابات العامة مع التوثيق ثم يعتمدها مراجع مخوّل. الفتاوى الخاصة لا تُعمم. هذه آلية RAG وتعلّم معرفي مراجع، وليست تدريبًا تلقائيًا لأوزان النموذج.

## اللغات والصوت

العربية، الإنجليزية، الفلبينية/التغالوغ (`fil`)، الفرنسية، الأمهرية (`am`)، السواحيلية (`sw`). عناوين الكتب وأسماء المستخدمين ونصوص المصادر تبقى بلغتها الأصلية. تُفهرس الكتب الجديدة بلغتها، ويمكن للمساعد ترجمة الأدلة المتاحة مع التصريح بالترجمة؛ عند غياب مصدر كافٍ يُحال السؤال إلى المختص.

الترجمات المضافة تحتاج تدقيقًا من متحدثين أصليين قبل الإطلاق؛ اكتمال مفاتيح الواجهة لا يثبت دقة لغوية بشرية. اختبارات الأمهرية والسواحيلية خصوصًا لا تغني عن مراجعة المصطلحات الشرعية.

الصوت المحسّن عبر الخادم؛ التسجيل باستخدام MediaRecorder أو رفع ملف، ومراجعة التفريغ قبل إرسال السؤال. القراءة على أجزاء MP3 مع أدوات تشغيل. عند غياب الخدمة يُستخدم صوت المتصفح إن توفر الصوت المناسب للغة. وجود لغة في القائمة لا يضمن دعم كل صوت محلي أو دقة النطق. إذن الميكروفون وHTTPS مطلوبان خارج localhost. جميع النصوص الصوتية مولدة آليًا وليست تلاوة معتمدة.

## مفتاح OpenAI والخصوصية

الإدارة المركزية ← الذكاء الاصطناعي والصوت. المفتاح يُحفظ في **`.enviroment.local`** داخل الخادم، خارج الملفات المنشورة وخارج Git. الملف خاص لكنه ليس مشفّرًا بذاته؛ احمه بصلاحيات نظام التشغيل وتشفير القرص والنسخ الاحتياطية. احتُفظ بمخزن DPAPI القديم للرجوع المحلي، ورُحّل المفتاح إلى الملف المطلوب دون طباعته. إذا ضبطت الاستضافة `OPENAI_API_KEY` كمتغير عملية فإنه يأخذ الأولوية، ويجب تعديله من الاستضافة.

عند استخدام الخدمة تُرسل الأسئلة وسياق آخر الرسائل والمقاطع اللازمة إلى OpenAI، والتسجيل عند طلب تفريغه، والنص عند طلب قراءته. لا يُرسل الكتاب كاملًا مع كل سؤال. واجهات الجلسات لا تعيد المفتاح. زر اختبار الاتصال/الصوت يستدعي خدمة مدفوعة؛ الاختبارات الآلية العادية لا تستدعيها.

## الاختبار والنسخ الاحتياطي

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s scripts -p test_*.py -v
.\.venv\Scripts\python.exe scripts/backup_data.py
```

مع توفر Node.js: `node scripts/test_frontend.cjs` لاختبارات حالة الواجهة والصلاحيات، و`node scripts/test_account_directory.cjs` للبحث والتصفية والصفوف القابلة للفتح في إدارة المستخدمين، دون متصفح أو شبكة. `python scripts/check_locales.py` يفحص تغطية نصوص اللغات محليًا.

تُنشئ الاختبارات قواعد مؤقتة وتستخدم بدائل لخدمة AI. لا تستخدم قاعدة التشغيل للاختبارات. فحص المتصفح المعزول: `python scripts/preview_test.py` على المنفذ **8081**، بحسابات اختبار فقط وخدمة AI معطلة. لا يُستخدم هذا المشغّل للنشر أو بيانات حقيقية. المنفذ **8080** هو المشروع الفعلي.

النسخ الاحتياطي أعلاه يشمل SQLite فقط. انسخ أيضًا `references/` و`data/library/` والصور وملف الأسرار عبر قناة آمنة ومشفرة. لا تستبدل قاعدة حية أثناء عمل الخادم. راجع [تقرير الأمان](docs/SECURITY.md) و[دليل النشر](docs/DEPLOYMENT.md).

##  والاستضافة وما بعد ذلك


التطبيق الجوال موجود في `../rihlatiApp`، مع تجربة متصفح من زر «تجربة التطبيق» أو `/app/`. ابنِ ملفاته أولًا كما في README الخاص به. يستخدم الحسابات والبيانات نفسها عبر `/app-api/` مع جلسات مستقلة ومنع الأدمن من الخادم. راجع [الفلوشارت](docs/WORKFLOW.md) و[نواقص التحكيم](docs/JUDGING_READINESS.md) و[مقارنة الاستضافة](docs/HOSTING_OPTIONS.md). بناء APK محلي لا يعني اختبار الأجهزة أو جاهزية المتاجر.
