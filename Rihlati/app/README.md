# واجهة رِحلتي

افتح المجلد الأب `Rihlati` في VS Code. تشغيل الواجهة يحتاج `scripts/api_server.py`؛ لا تفتح HTML مباشرة.

راجع [README الرئيسي](../README.md) للتشغيل والحسابات والمكتبة والصوت، و[تقرير الأمان](../docs/SECURITY.md) لحدود الفحص.

`app.js` للرحلة والحوار والمكتب، و`accounts.js` للعضويات والإدارة، و`i18n.js` مع `locales.json` للترجمات. عدم ظهور زر ليس آلية حماية؛ التحقق من الصلاحيات يتم في الخادم أيضًا.
