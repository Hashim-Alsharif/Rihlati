# فلوشارت رِحلتي للويب والتطبيق

فريق سراج | مراجعة 4 أكتوبر 2026. المسارات نسبية إلى جذر المستودع، وليست امتدادات جهاز المطور. هذه المخططات تصف التنفيذ الحالي، ولا تعني اكتمال النشر أو اعتماد المخرجات شرعيًا. أصل الفكرة: `Rihlati/docs/idea.docx`.

## المكونات المشتركة

```mermaid
flowchart TB
  W[الويب Rihlati/app] --> WA[API /api/ وجلسة ويب]
  P[تجربة التطبيق /app/] --> MA[API /app-api/ وجلسة تطبيق]
  A[تطبيق Android وiOS في rihlatiApp] -->|HTTPS| MA
  WA --> G[Flask وWaitress والتحقق من الدور والنطاق وCSRF]
  MA --> G
  G --> D[(SQLite مشتركة للحسابات والتقدم والتذاكر والمعرفة)]
  G --> F[ملفات مراجع وصور خاصة لا تعرض إلا بإذن]
  G --> R[استرجاع BM25 من المعرفة المعتمدة]
  R --> O[مزود AI خادمي عند تفعيله]
  G --> S[تحويل الكلام إلى نص وقراءة النص صوتيًا]
  O --> E[جواب بمصدر وصفحة أو إحالة]
  R -->|دون مزود| E
```

## دخول الويب والصلاحيات

```mermaid
flowchart TD
  Start[فتح الويب] --> Login[دخول أو تسجيل]
  Login --> Role{نوع العضوية}
  Role -->|مستفيد| Member[اختيار 1 إلى 3 مكاتب معتمدة]
  Member --> Home[الرحلة والشات والأسئلة الشائعة والتذاكر والحساب]
  Role -->|مكتب جديد| Pending[انتظار اعتماد الإدارة]
  Pending --> Office[لوحة المكتب والمستفيدون المرتبطون وتذاكر المكتب]
  Role -->|أدمن| Admin[لوحة مركزية وفق صلاحيات الموظف]
  Admin --> Manage[اعتماد المكاتب والمستخدمين والمكتبة والتصحيحات والإعدادات]
  Home --> Profile[تغيير الصورة والبيانات وكلمة المرور]
  Office --> Profile
  Admin --> Profile
```

## السؤال والجواب والمختص

```mermaid
flowchart TD
  Q[سؤال مكتوب أو تسجيل صوتي] --> V[تفريغ الصوت ومراجعة النص قبل الإرسال]
  V --> C[سياق المحادثة ولغة المستفيد]
  C --> R[بحث في المصادر والتصحيحات المعتمدة]
  R --> Enough{هل الدليل كافٍ}
  Enough -->|نعم| A[صياغة جواب من الدليل والتحقق الآلي عند تفعيل المزود]
  A --> Show[عرض الجواب ومصدره وصفحته وزر الاستماع]
  Enough -->|لا| T[إنشاء تذكرة للمكتب المختار أو الإدارة]
  Show --> Choice{هل يريد المستخدم المختص}
  Choice -->|نعم| T
  Choice -->|لا| More[متابعة المحادثة ومساعدة أخرى]
  T --> Reply[رد المختص إلى التذكرة والمحادثة]
  Reply --> Review{هل الرد عام وموثق وقابل للتعميم}
  Review -->|نعم| Proposal[اقتراح تصحيح ينتظر اعتماد المراجع]
  Proposal --> Approved[معرفة معتمدة مع نسبتها للمراجع]
  Approved --> R
  Review -->|لا| Private[يبقى ردًا خاصًا ولا يعمم]
```

التحقق الآلي يقلل الأخطاء ولا يمثل اعتمادًا شرعيًا. التعلّم هنا إضافة معرفة مصححة معتمدة للاسترجاع، وليس تدريبًا تلقائيًا لأوزان النموذج. لا تدخل إجابة مولّدة غير مراجعة إلى المعرفة الموثوقة.

## إضافة مرجع ومراجعته

```mermaid
flowchart TD
  Upload[مكتب أو أدمن يرفع PDF ويحدد اللغة والمستوى والموضوع] --> Attribution[تسجيل الرافع والمكتب وهوية المصدر]
  Attribution --> Extract[استخراج النص الرقمي أو OCR الاختياري]
  Extract --> Pages[صفحات ومقاطع وحالة جودة الاستخراج]
  Pages --> Review[بحث ومقارنة بالنص الأصلي وتصحيح الصفحات]
  Review --> Decision{اعتماد الإدارة المخولة}
  Decision -->|مقبول| Index[إتاحته للاسترجاع مع المصدر والصفحة]
  Decision -->|غير جاهز| Pending[يبقى خارج الإجابات المعتمدة]
  Index --> Withdraw[سحب الاعتماد عند اكتشاف خطأ]
  Withdraw --> Pending
```

الاعتماد التقني في قاعدة البيانات ليس إثبات حقوق النشر أو شهادة مراجعة شرعية خارجية. يجب توثيق الجهة والمؤلف والطبعة وإذن الإتاحة قبل النشر العام، مع الانتباه لاختلاف رقم صفحة PDF عن ترقيم الكتاب.

## الأدوات والتحكم

| الجزء | الأداة الحالية | الوظيفة والحدود |
| --- | --- | --- |
| واجهات الويب والهاتف | HTML وCSS وJavaScript | ست لغات واتجاه RTL وواجهة هاتف خاصة |
| تغليف الهاتف | Capacitor 8 | Android وiOS وتكامل الرجوع والكيبورد والاهتزاز |
| الخادم | Python وFlask وWaitress | التحقق من المستخدم والنطاق والصلاحيات |
| قاعدة البيانات | SQLite | حسابات وتذاكر وتقدم وصفحات ومقاطع على خادم واحد |
| كلمات المرور | Argon2id | تجزئة بملح عشوائي، ليست تشفيرًا قابلًا للفك |
| الاسترجاع | BM25 | بحث نصي، ليس قاعدة متجهات |
| المساعد والصوت | مزود OpenAI عبر الخادم | يحتاج مفتاحًا ورصيدًا وضبط خصوصية وتقييمًا فعليًا |
| الكتب | pypdf وPDF.js | استخراج على الخادم وقراءة داخل التطبيق |
| OCR الاختياري | Tesseract.js وPoppler | يحتاج لغات مدربة ومراجعة للصفحات الضعيفة |

## ملفات مرجعية للمطور

الويب `Rihlati/app` والخادم `Rihlati/scripts/api_server.py` والحسابات `accounts.py` والمعرفة `knowledge.py` والمساعد `assistant_engine.py`. واجهة الهاتف `rihlatiApp/src` وبناؤها `rihlatiApp/scripts/build.mjs`. لا تعديل يدويًا في `www`. لا تُنسخ قاعدة حية إلى Git. تعليمات التشغيل والنشر في README ودليل DEPLOYMENT.
