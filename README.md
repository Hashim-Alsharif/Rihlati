# رِحلتي من فريق سراج

مستودع موحد للويب والتطبيق. بناء وتطوير فريق سراج. النسخة مخصصة للتطوير والتحكيم وليست اعتمادًا أمنيًا لإطلاق عام.

المستودع: [Hashim-Alsharif/Rihlati](https://github.com/Hashim-Alsharif/Rihlati). يجري تجهيز استضافة HTTPS؛ لا يعني وجود الكود هنا أن السيرفر منشور أو جاهز للإنتاج.

- `Rihlati/`: الويب والخادم وقاعدة البيانات الخاصة ومكتبة المراجع.
- `rihlatiApp/`: واجهة الهاتف ومشروعا Android وiOS؛ يشتركان في خادم رحلتي وحساباته.
- `Rihlati/docs/WORKFLOW.md`: مخططات سير العمل والمكونات والصلاحيات.
- `Rihlati/docs/JUDGING_READINESS.md`: مطابقة متطلبات التحكيم والاختبارات والنواقص.
- `Rihlati/docs/HOSTING_OPTIONS.md`: خيارات الاستضافة وتقدير شهرين.
- `Rihlati/deploy/README.md`: تشغيل Ubuntu وCaddy وsystemd والنسخ الاحتياطي.

افتح هذا المجلد في VS Code. على جهاز جديد اتبع README داخل كل مشروع. لتجربة التطبيق ابنِ `rihlatiApp` بالأمر `npm ci` ثم `npm run build`، وشغّل خادم الويب حسب `Rihlati/README.md`. الويب محليًا `http://localhost:8080/` والتطبيق `http://localhost:8080/app/`.

لا ترفع كامل محتويات جهاز التطوير: لا أسرار أو حسابات أو محادثات أو نسخ قواعد أو كتب دون إذن توزيع. راجع قائمة الملفات قبل أي commit. المستودع العام المطلوب للمسابقة لا يعني نشر بيانات المستفيدين. اختيار ترخيص نشر الكود واعتماد حقوق الكتب قرار لفريق سراج قبل النشر.

## المكتبة المرجعية

تُنشر الكتب المصرّح بتوزيعها كمرفق منفصل في [الإصدارات](https://github.com/Hashim-Alsharif/Rihlati/releases)، لتبقى نسخة الكود خفيفة. حزمة المكتبة تحتوي PDF والنصوص مع المصدر والصفحة وحالة المراجعة، ولا تحتوي قاعدة الأعضاء أو المحادثات أو التذاكر أو التصحيحات الخاصة أو مفاتيح الخدمة. لا تعتمد المادة التي حالتها للمراجعة تلقائيًا. حقوق كل كتاب محفوظة لأصحابه؛ إذن صاحب المشروع بنشر الحزمة لا يغيّر ترخيص الكتب.

على تثبيت جديد يمكن تنزيل الحزمة ورفع ملفات PDF من واجهة إدارة المكتبة ومراجعتها. لا تستبدل بها قاعدة بيانات قائمة. توثيق الفهرسة والاستخراج في `Rihlati/PROJECT_ARCHITECTURE.md`، وأداة التصدير ذات الحقول المحددة في `Rihlati/scripts/export_public_library.py`.
