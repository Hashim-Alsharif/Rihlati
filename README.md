# رِحلتي من فريق سراج

مستودع موحد للويب والتطبيق. بناء وتطوير فريق سراج. النسخة مخصصة للتطوير والتحكيم وليست اعتمادًا أمنيًا لإطلاق عام.

## Site Information Guide and Flowchart

[عرض وتحميل دليل الموقع والتطبيق ومخططات التدفق (PDF)](./Site%20Information%20Guide%20and%20Flowchart.pdf)

دليل عربي من 12 صفحة يوضح بنية المنصة، رحلة المستفيد، الصلاحيات، سير السؤال والتصعيد للمختص، المكتبة وآلية مراجعة المعرفة، وروابط الموقع والتطبيق والفيديو والمستودع. يتضمن حالة التحكيم وخطة الاستمرار، وتوثيق التعاون مع مكتب المسلمين الجدد بالرياض في توفير معظم الكتب والمنشورات والمطويات، وأسماء فريق سراج وتخصصاتهم في الصفحة الأخيرة. آخر تحديث: 5 أكتوبر 2026.

المستودع: [Hashim-Alsharif/Rihlati](https://github.com/Hashim-Alsharif/Rihlati). نُشرت نسخة التجربة والتحكيم يوم 5 أكتوبر 2026: [الموقع](https://rihlati.me/) و[تجربة التطبيق بالمتصفح](https://rihlati.me/app/). يعمل الرابطان عبر HTTPS على الخادم نفسه. هذا نشر تجريبي، وليس شهادة جاهزية لإطلاق مؤسسي عام؛ راجع حدود التحقق في `Rihlati/docs/JUDGING_READINESS.md`.

- `Rihlati/`: الويب والخادم وقاعدة البيانات الخاصة ومكتبة المراجع.
- `rihlatiApp/`: واجهة الهاتف ومشروعا Android وiOS؛ يشتركان في خادم رحلتي وحساباته.
- `Rihlati/docs/WORKFLOW.md`: مخططات سير العمل والمكونات والصلاحيات.
- `Rihlati/docs/JUDGING_READINESS.md`: مطابقة متطلبات التحكيم والاختبارات والنواقص.
- `Rihlati/docs/HOSTING_OPTIONS.md`: خيارات الاستضافة وتقدير شهرين.
- `Rihlati/deploy/README.md`: تشغيل Ubuntu وCaddy وsystemd والنسخ الاحتياطي.

افتح هذا المجلد في VS Code. على جهاز جديد اتبع README داخل كل مشروع. لتجربة التطبيق ابنِ `rihlatiApp` بالأمر `npm ci` ثم `npm run build`، وشغّل خادم الويب حسب `Rihlati/README.md`. الويب محليًا `http://localhost:8080/` والتطبيق `http://localhost:8080/app/`.

لا ترفع كامل محتويات جهاز التطوير: لا أسرار أو حسابات أو محادثات أو نسخ قواعد أو كتب دون إذن توزيع. راجع قائمة الملفات قبل أي commit. المستودع العام المطلوب للمسابقة لا يعني نشر بيانات المستفيدين. أجاز صاحب المشروع نشر حزمة المكتبة؛ لم يُحدد ترخيص عام للكود بعد، ولا يُفترض تلقائيًا ترخيص MIT.
